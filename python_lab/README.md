# Python Programming Lab

This project contains simple Python programs for Unit 1 and Unit 2 of a Python Programming Lab.

## Project structure

```text
python_lab/
|
|-- README.md
|
|-- unit_1/
|   |-- 01_student_information.py
|   |-- 02_scientific_calculator.py
|   |-- 03_mathematical_calculator.py
|   `-- 04_electricity_bill_generator.py
|
|-- unit_2/
|   |-- 01_prime_number.py
|   |-- 02_factorial.py
|   |-- 03_fibonacci_series.py
|   |-- 04_random_otp.py
|   `-- 05_fibonacci_recursion.py
|
|-- unit_3/
|-- unit_4/
`-- unit_5/
```

Units 3, 4, and 5 are intentionally empty because their programs were not included in the available lab material.

## Requirements

- Python 3
- No external libraries are required.

## Running programs in VS Code

1. Open the `python_lab` folder in VS Code.
2. Open the Python file you want to run.
3. Select a Python 3 interpreter if VS Code asks you to choose one.
4. Click the Run Python File button in the top-right corner, or open the integrated terminal.
5. Run the file with a command such as:

```text
python unit_1/01_student_information.py
```

On Windows, `py` can also be used:

```text
py unit_1/01_student_information.py
```

Run any other file by replacing the path with the file you want to execute.

## Programs

### Unit 1

- Student information and academic summary
- Scientific calculator for two numbers
- Mathematical calculator using built-in functions and the `math` module
- Electricity bill generator

### Unit 2

- Prime number check
- Factorial using a loop
- Fibonacci series using a loop
- Random 4-digit or 6-digit OTP generation
- Fibonacci series using recursion
